APATURE GATE - ARCHITECTURE

The neutral design reviewer for AI-generated frontend PRs.
Gate is GitHub-native review for rendered UI. It discovers a preview deploy, schedules exactly the current PR head, calls verdict, then publishes annotated findings back to GitHub. Gate owns the shipping workflow; the shared engine owns capture, context, Qwen3-VL critique, validation, eval, and feedback primitives.

Gate orchestration

Newest push wins, stale reviews never publish

  • Queue supersession key is repo#pr; durable completed-review identity is (repo, pr, head_sha).
  • Set current_sha[repo#pr] on enqueue; cancel old active work when possible; re-check at every expensive boundary.
  • Mandatory publish guard before editing the sticky comment or Check Run.

Shared judgment boundary

What Gate asks for

  • Review this current PR head against this repo's UI DNA and config.
  • Return only validated findings with route, viewport, element ref, evidence, suggestion, and severity.
  • Use Qwen3-VL through verdict; Gate never hard-codes a model vendor.

What verdict owns

  • Browser capture, readiness, tiling, DOM geometry, computed styles, and page-health facts.
